# Support

## Getting Help

- **Bug reports**: [Open an issue](https://github.com/helpers4/.github/issues/new?template=bug_report.md) on the relevant repository
- **Questions**: Use [GitHub Discussions](https://github.com/orgs/helpers4/discussions) or open an issue
- **Documentation**: Visit [helpers4.dev](https://helpers4.dev)

## Projects

| Project | Repository | Description |
|---|---|---|
| TypeScript Helpers | [helpers4/typescript](https://github.com/helpers4/typescript) | TypeScript utility functions |
| DevContainer Features | [helpers4/devcontainer](https://github.com/helpers4/devcontainer) | Dev Container features |
| GitHub Actions | [helpers4/action](https://github.com/helpers4/action) | Reusable GitHub Actions |
| Website | [helpers4/website](https://github.com/helpers4/website) | Documentation website |

## Response Time

This is a community-maintained project. We do our best to respond promptly, but please allow a few days for a response.
